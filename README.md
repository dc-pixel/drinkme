# DrinkMe

Premium beverage and party-essentials delivery storefront built with Next.js, TypeScript, Framer Motion, and responsive CSS.

## Features

- Premium responsive homepage
- Beverage, mixer, glassware, snack and party categories
- Search and product discovery
- Add-to-cart and quantity controls
- Favorites
- Animated cart drawer
- Location-first delivery messaging
- Combo / party-pack concept section
- Vercel-ready Next.js structure

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Vercel

Import `dc-pixel/drinkme` into Vercel. The framework is Next.js and the default build command is `next build`.

The current demo uses seeded client-side data and does not require a database or secret environment variables to render the storefront.
